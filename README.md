# Officina Moto

Gioco gestionale di Massi: ripari le moto dei clienti con i minigiochi, compri e rivendi l'usato, personalizzi, assumi meccanici, apri nuove sedi e porti la squadra corse fino al Mondiale. Partita senza fine con 44 traguardi; l'officina lavora anche a gioco chiuso.

- **Android:** https://github.com/massxxx/officina-moto-/releases/latest/download/OfficinaMoto.apk
- Il gioco è in `web/` (index.html + gioco.js). Ogni push su `main` ricompila l'APK con Capacitor e lo pubblica nella release `app`.
